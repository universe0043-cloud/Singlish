# Singlish 发音试标说明 v0.4

本版沿用 v0.3 的 20 条日常对话例句和 42 条标注，为 `pilot-020` 补入 `Gimme a` 的连读。现有弱读 18 条、连读 12 条、省音 4 条、变音 5 条、口语缩读 4 条，共 43 条。所有例句仍为 `pending_human_review`。

## 字段与位置

| 层级 | 字段 | 约定 |
| --- | --- | --- |
| 例句 | `id` | 本批唯一编号 `pilot-001` 至 `pilot-020`。 |
| 例句 | `source_type` | 固定为 `daily_dialogue`。 |
| 例句 | `input_text` | 原句，保留大小写、空格和标点。 |
| 例句 | `review_status` | 固定为 `pending_human_review`，表示试标草稿。 |
| 例句 | `annotations` | 数组。同一句可以有多条标注，标注区间可以重叠。同一句内，类别、`start` 和 `end` 都相同的标注只记一次。 |
| 标注 | `text` | 从原句逐字复制的连续片段。 |
| 标注 | `start`、`end` | Python 字符串索引，从 0 开始，左闭右开。程序按完整词或词组查找目标片段并计算 `end = start + len(text)`，逐条验证 `input_text[start:end] == text`。同一完整片段重复时，用原文中唯一、仅包含一次完整目标片段的 `context` 消歧。 |
| 标注 | `category` | 取值见下表。 |
| 标注 | `evidence` | `text_observed` 表示目标口语缩读拼写直接出现在原文中。其余四类用 `text_candidate`，表示文本提供了值得练习的条件。 |
| 标注 | `actual_pronunciation` | 全部为 `uncertain`。实际读音需要音频证据。 |
| 标注 | `speaking_tip_zh` | 中文练习提示，可以给出对照读法或描述可能出现的条件。 |

证据字段回答「从文字里看到了什么或推测了什么」，实际发音字段回答「是否有证据确认人是这么读的」。例如看到 `wanna` 可以确认拼写出现，实际发音仍为 `uncertain`。类别 `weak_forms`、`linking`、`reduction` 沿用项目已有名称，`elision` 和 `sound_change` 是这份试标数据的新增类别。

例如 `Pick it` 与 `it up` 在 `it` 上重叠，两个连读区间都保留。`Can` 的弱读标注也可以与 `Can I` 的连读标注重叠。`pilot-019` 的 `gotta` 在同一区间分别标为口语缩读和变音。所有新增标注均为 `text_candidate` 和 `uncertain`，中文提示写明读法成立的条件。

## 五类判断规则

| 类别 | 判断规则 | 标注范围 |
| --- | --- | --- |
| 弱读 `weak_forms` | 功能词在句中可能不承载重音，并有可教的弱式，如 `can`、`to`、`and`、`of`。若词承担回答或对比重点，按完整读法教学。 | 标该功能词。 |
| 连读 `linking` | 按相邻词的词界音素判断。收录辅音接元音，以及两个元音之间可用轻滑音 [j] 或 [w] 自然过渡的候选。两词之间无明显停顿时才练习连读。需要先省去其他音才能成立的连读留作扩展。 | 标连续的两个词。 |
| 省音 `elision` | 本版聚焦自然快读时，前词以辅音丛结尾且后词以辅音开始时，前词末尾的 /t/ 或 /d/ 可能省去。例句包括 `last night`、`next week`、`old man`、`walked down`。保留完整读法供对照。 | 标两个词，在提示中指出可能省去的音。 |
| 变音 `sound_change` | 收录可具体说明的语流音变。包括 /d/ 或 /t/ 与后续 /j/ 的合音（`Did you`、`Don't you`）、相邻音影响发音部位（`ten people` 里 /n/ 在 /p/ 前可能接近 [m]），以及美式口语中的舌尖轻弹音（`water` 的 /t/ 可能实现为 [ɾ]）。 | 跨词变化标词对，词内变化标整词。 |
| 口语缩读 `reduction` | 仅在原文直接出现可确认的非正式缩读拼写时标注。本批收 `wanna`、`gonna`、`gotta`、`Gimme`。常规书面缩写暂不纳入。 | 标原文中的缩读形式，保留原大小写。 |

`water` 和 `gotta` 的变音教学提示均注明「常见美式读法」。练习时重读首音节，舌尖在较轻的后一音节前快速触碰上齿龈一次，形成轻弹音 [ɾ]。是否采用这种读法取决于口音和说话方式。

## 连读的词界示例

| 词界 | 开发示例 | 本版如何处理 |
| --- | --- | --- |
| 辅音接元音 | `Hold on` | 可标。前词的 /d/ 接后词开头的元音。 |
| 元音接元音 | `see it`、`go out` | 可标。提示具体的轻滑音，例如 `see it` 的 [j] 或 `go out` 的 [w]。练习时轻轻带过，无需把过渡音读成独立的重音节。 |
| 辅音接辅音或元音接辅音 | `turn left` | 超出本版连读范围。`turn left` 是 /n/ 接 /l/。 |

`pilot-020` 的 `Gimme a` 是 [j] 过渡的例子。原有 `Gimme` 口语缩读和 `a` 弱读保留。连读的 `evidence` 为 `text_candidate`，`actual_pronunciation` 为 `uncertain`。

## 五个边界

| 例子 | 本版如何处理 |
| --- | --- |
| `Yes, I can.` | `can` 在简短回答里承担重点，按完整读法教学，不标为弱读候选。 |
| `turn left` | /n/ 接 /l/，两边都是辅音，超出本版连读范围。 |
| `next item` | `item` 以元音开始，不套用 `next week` 中辅音前可能省去词尾 /t/ 的规则。 |
| `did I` 与 `did you` | `did I` 的 /d/ 可接上 `I` 开头的元音，标为连读候选。 `did you` 中 /d/ 和 /j/ 可能合成 /dʒ/，属于变音候选。 |
| `won't` | 常规书面缩写，超出本版口语缩读范围。`I'm` 和 `Don't` 本身也按这一边界处理。 |
